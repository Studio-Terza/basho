# sight-loops

Problem: in towns, many sights were hard to place relative to each other and the route.

L1 A loop is a goal made of an ordered list of sights, each with a planned time, typed in the trip file.
L2 A loop shows on one map as numbered stops in order, without colour.
D1 Loop type and file format.
D2 Map and goal page rendering. after: D1
D3 Convert existing town sightseeing that already lists several sights in order, such as Sakata, using only what the trip file already holds. after: D1
Out: new sights, route changes, new times.
