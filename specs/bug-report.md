# bug-report

Problem: on the trip there was no way to capture a bug with its context.

L1 One action captures a report offline, with no typing required.
L2 A report records what was on screen and the tracker state at that moment.
L3 Reports never leave the phone except by the user's explicit export.
D1 Report type and local store.
D2 Capture: screen, step, time, position, tracker state, recent tracker decisions. after: D1
D3 Triggers: two-finger long press, and a menu button. after: D2
D4 List, and export. after: D1
D5 Optional text note. after: D1
Out: voice notes, screenshots if the platform can't capture them offline, uploads.
