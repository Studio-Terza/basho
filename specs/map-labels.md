# map-labels

Problem: kanji-only map names give the reader nothing to read.

L1 A labelled feature shows kana above kanji.
L2 A generated reading is visibly marked, without colour; an OSM reading is not.
L3 Works offline, with nothing added at runtime beyond label data.
D1 Readings at tile build: OSM `name:ja-Hira`, `name:ja_kana` or similar first, then generated by a Rust morphological analyzer such as `lindera`, at build time only.
D2 Two-line labels in the map style. after: D1
Out: translation, romaji, font changes beyond what's needed.
